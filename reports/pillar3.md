|---|---|---|

| **EU CC2** | Reconciliation own funds ↔ účetní rozvaha | capital reconciliation |

| **EU LIQ1** | LCR | „LCR?" |
| **EU LIQ2 / LIQ2 ***| NSFR | „NSFR?" |

| **EU CR** *(skupina listů)* | Credit risk (kvalita, expozice, CRM) | úvěrové riziko |
| **EU INS1 / INS2** | Insurance participations / FICOD | pojistné účasti |

1. Najdi tabulku výše → otevři list v živém workbooku.
2. Pro kapitál/RWA/ratios k nejnovějšímu datu preferuj COREP 2026-03-31.
3. Cituj: hodnota + table code (např. `EU KM1`) + reportingové datum
   (2025-12-31 pro tento workbook).
