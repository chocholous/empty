## Klíčové patterny

- **Declarative Agent struktura**: `appPackage/manifest.json` + `appPackage/declarativeAgent.json` + `appPackage/instruction.txt` (nebo `.md`)
- **API Plugin pattern**: `appPackage/ai-plugin.json` + `appPackage/apiSpecificationFile/openapi.yaml` + backend (Azure Functions)
- **Graph API jako plugin**: OpenAPI spec volající `https://graph.microsoft.com` endpointy (search, tasks)
- **TypeSpec pattern**: `.tsp` soubory definující API schema, kompilace do OpenAPI -- viz `tspconfig.yaml`
- **OAuth flow**: `da-repairs-oauth/` ukazuje Easy Auth na Azure Functions; `da-repairs-oauth-validated/` přidává validaci tokenů
- **Adaptive Cards**: `da-adaptive-card-dialog/` (dialog) a `da-adaptive-card-inline-edit/` (inline edit) ukazují response rendering
- **Teams Toolkit**: Většina samples používá `teamsapp.yml` nebo `m365agents.yml` pro provisioning přes Teams Toolkit
- **Multi-language**: Backends v TypeScript (Azure Functions), C# (.NET), Python (Flask)

## Prerequisites

- Microsoft 365 tenant s Copilot licencí (nebo Copilot Chat)
- Teams Toolkit (VS Code extension) pro provisioning a deployment
- Node.js 18+ pro TypeScript samples
- .NET 8+ pro C# samples (cext-trey-research-csharp, da-MyAdvancedCommsBuddy)
- Python 3.10+ pro Python samples (cext-trey-research-python)
- Azure subscription pro Azure Functions backends
- Pro TypeSpec samples: `npm install` (TypeSpec compiler je npm závislost)
- Pro Graph API plugins: Azure AD app registration s příslušnými Graph permissions
- Pro ServiceNow samples: ServiceNow instance s přístupovými údaji
